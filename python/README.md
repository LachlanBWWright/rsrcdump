# Python rsrcdump

This directory contains the original Python implementation of rsrcdump.

## Structure

- `rsrcdump/` - Python package source code
- `tests/` - Python test files
- `output/` - Test output files (gitignored)
- `enhanced_rsrcdump.py` - Enhanced version with additional features
- `rsrcdump.sh` - Shell script wrapper

## Usage

See the main repository README for usage instructions.

## Testing

Run tests from the repository root:

```bash
python -m pytest python/tests/
```
